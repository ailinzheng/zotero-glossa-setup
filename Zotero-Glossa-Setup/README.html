GLOSSA 0.2.0 · 中文安装指南

在 Zotero 里，和 Claude 一起读论文。

安装助手已包含作者发布的原版插件，无需去 GitHub 找下载按钮。运行对应脚本部署文件，再在 Zotero 内确认启用并填写你已有的 API 密钥。

先看 Zotero 版本：本版本插件仅兼容 10.0.6 及以后的正式版 10.x。在“帮助 → 关于 Zotero”（Mac：Zotero 菜单）查看版本。其他主版本或测试版请先核对兼容性；助手不会自动升级 Zotero。

① 解压、退出 Zotero、运行脚本

先把整个 ZIP 解压出来。保存工作，并完全退出 Zotero。不要在压缩包预览窗口内直接运行。

Windows

双击 START-Windows.cmd。

使用系统自带 PowerShell，无需管理员权限。若系统或单位策略阻止脚本，直接使用下面的“手动安装”方式。

macOS

双击 START-macOS.command。

退出 Zotero 请使用 Command + Q。若文件缺少执行权限，可在终端输入 bash ，把该文件拖进终端，再按回车；若系统阻止执行，使用手动安装。

脚本会核对版本和文件校验值，识别配置文件；如有多个 Zotero 配置，会让你选择。安装阶段无需联网。脚本不会强制关闭 Zotero。

② 在 Zotero 确认插件

  1. 脚本部署完成后会尝试打开 Zotero。进入 工具 → 插件。
  2. 找到 Glossa for Zotero。如果显示“启用”或安装确认，点击一次；如果提示重启，先重启。
  3. 选中一篇带 PDF 的文献，点击右侧导航栏的 Glossa 图标。

本助手自动部署文件，首次启用可能仍需在 Zotero 内确认。只有插件已启用、面板正常出现，才算插件安装完成。

没有出现插件？用 Zotero 自带的安装功能
  1. 打开 工具 → 插件。
  2. 把本文件夹中 payload/glossa-zotero-0.2.0.xpi 拖进插件窗口；或在齿轮菜单选择“从文件安装插件…”，选中该文件。
  3. 按提示完成安装，必要时重启 Zotero。不要解压 XPI，也不要把 XPI 安装到浏览器。

③ 填写你已有的 Claude 密钥

在 Glossa 面板中点击输入框下方的模型名称 → 添加 API 服务。

字段Anthropic 官方密钥的填法
服务预设Anthropic
协议Anthropic
API 地址https://api.anthropic.com
API Key仅在 Zotero 内粘贴你自己的密钥。
模型 ID点击获取模型列表，从账户可用模型中选择。

点击保存配置，回到对话面板发送一个问题。

如果密钥来自第三方服务商：使用该服务商给你的 API 地址、协议和模型 ID。仅凭“Claude 密钥”不能确定地址；有些服务商采用 Anthropic 协议，有些采用 OpenAI 兼容协议。模型列表接口不受支持时，可手动填写服务商提供的模型 ID。

此流程让你在 Zotero 内调用 Claude API。它不配置 Claude 桌面应用的 MCP，也不连接 Claude 桌面应用的聊天记录。安装脚本不接收密钥、不调用付费 API；第一次发送问题会使用你的 API 额度。

④ 用一篇论文验证连接

选中论文并打开 PDF；需要读取正文时，在 Glossa 中开启“全文”。发送：

请用中文概括本文的研究问题、数据来源、研究方法、主要结论与局限。对关键表述标注可回溯的来源；如果文中没有依据，请明确说明。

收到有来源标记的回答后，即可使用 /summarize、/translate、/explain 或 /compare。保存回答时，切换到 Act → 保存为笔记。

这个版本每次最多比较六篇文献，PDF 正文最多读取每篇前 40 页，正文上下文总量有上限；扫描 PDF 需要先做 OCR，不能把“全文”理解为整篇均已输入模型。

遇到问题时

提示版本不兼容

确认是 Zotero 10.0.6 或更高的正式版 10.x。7/8/9、10.0.0–10.0.5、11 或测试版不在本包兼容范围内。不要修改插件的版本声明强行安装。

装过 Glossa 0.1.0，或已经有更新的版本

作者要求 0.1.0 先在插件管理器移除，再重启 Zotero，之后安装 0.2.0。助手遇到比 0.2.0 更新的插件会停止，避免降级。

401 / 403，或者获取模型列表失败

核对密钥是否有效、是否有该服务和模型的权限，API 地址是否对应发放密钥的服务商。服务商可能不支持模型列表；这种情况可手动填它提供的模型 ID。连接超时则先检查 Zotero 能否访问该 API 服务。

404 / 429 或余额不足

404：核对 API 地址、协议和模型 ID。429：可能是请求频率或额度限制，按服务商说明处理。余额不足：到发放密钥的服务商账户检查 API 额度。

脚本没有找到 Zotero 或配置文件

请先正常启动 Zotero 一次再退出。自定义便携版、配置位置或受组织管理的安装，请用第②步的手动安装功能。助手不会创建或猜测新的文献库。

脚本修改了哪些文件？如何撤回？

助手只部署 Glossa XPI，并清除 prefs.js 中两个启动缓存标记（extensions.lastAppBuildId、extensions.lastAppVersion），让 Zotero 重新扫描插件。安全策略、已有插件的禁用状态、数据库与 PDF 不由助手更改。

修改前的文件存放在所选配置目录的 glossa-setup-backups/时间戳/。previous.xpi 是旧版插件；prefs.js 是当时的设置备份。只有需要恢复那一时刻的设置时才还原，且先完全退出 Zotero。普通卸载直接使用“工具 → 插件 → 移除”。
